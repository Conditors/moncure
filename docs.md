# Документация разработки и запуска

Этот файл предназначен для практических инструкций по работе с Moncure.

По мере настройки проекта здесь будут добавлены:

- требования к локальному окружению;
- установка Python и uv;
- настройка переменных окружения;
- запуск отдельного сервиса;
- запуск инфраструктуры через Docker Compose;
- создание и применение миграций Alembic;
- запуск тестов;
- Ruff и другие проверки качества;
- диагностика RabbitMQ и PostgreSQL;
- остановка и очистка локального окружения;
- типичные проблемы и способы их решения.

Команды должны добавляться только после того, как они проверены в актуальной конфигурации проекта.
